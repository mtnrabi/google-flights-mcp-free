# PINNED EXACTLY, DELIBERATELY. This SDK's failure modes do not raise -- they
# no-op and CPM silently goes to zero, so a bad version shows up on a revenue
# chart rather than in a stack trace, and a floor would let one land on an
# unattended Vercel redeploy. 0.9.10 is the version the suite is verified
# against. `rowLink` (what makes each row click through to its buy_link)
# arrived in 0.9.1; 0.9.2 fixed a middleware early-return that left CLI hosts
# with no visible ad at all. 0.9.5-0.9.10 (checked 2026-09-06, diffed against
# 0.9.4) only ADD: a CLI delivery beacon (client.py/middleware.py, fired via
# asyncio.create_task inside the existing async request path, never
# asyncio.run -- best-effort, non-blocking) and new opt-in `template=`
# formats on lulu_ads.widget.register_sponsored_widget (banner/hero/flip-card/
# etc, default stays "card"). We don't pass `template=` or `background_image=`
# at our one call site (src/server.py), so behaviour there is unchanged.
# `lulu_ads/widgets.py` -- FRAME_HTML, result_widget_html, the rowLink guard
# our _register_result_widget depends on -- is BYTE-IDENTICAL between 0.9.4
# and 0.9.10 (md5 match); none of the above touches it.
#

# this version's, then re-run tests/test_ads.py -- specifically

# served widget bytes. That test fails on 0.8.5 and passes on 0.9.2+, so it
